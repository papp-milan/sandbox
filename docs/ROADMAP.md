# Roadmap

Sandbox is an evolving playground, not a product with a fixed finish line.

## Platform
- [x] Repository and application structure
- [x] React + TypeScript + Vite frontend
- [x] Monochrome Swiss-grid starting layout
- [x] Spring Boot API skeleton
- [ ] Feature Explorer (idea / planned / in progress / done)
- [ ] CI checks
- [ ] Deploy at sandbox.pappmilan.com

## Labs
- [ ] Visual Lab — interactive 3D mathematical surfaces and graphics
- [ ] Audio Lab — SomaFM radio, audio tools and visualizations
- [ ] Algorithm Visualizer — sorting, pathfinding and data structures
- [ ] Data Lab — data exploration and visualization
- [ ] Event Lab — Kafka and event streaming
- [ ] AI Lab — LLMs, agents and prompt experiments
- [ ] Workflow Lab — BPMN and Camunda
- [ ] Backend Lab — Spring Boot and API experiments

## Principles
- Add features when there is genuine curiosity.
- Keep experiments small and modular.
- Avoid infrastructure before it has a real use case.
